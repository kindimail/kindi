# Security Policy

## Reporting a vulnerability

Please do **not** open a public issue for security problems.

Report privately through GitHub: **Security → Report a vulnerability** on this repository.
Email: security@kindimail.com (active once the domain is set up).

We will confirm receipt within 3 working days and keep you updated until a fix is released.

## Supported versions

Kindi is pre-1.0. Only the latest release receives security fixes.
